# <img src="media/icon.png" alt="Fluxstream Icon" width="32" height="32"> Fluxstream

High-speed racing game where you compete against AI rivals on a track-based system with slipstream mechanics. Inspired by [bit generations: dotstream](https://en.wikipedia.org/wiki/Bit_Generations).

## Gameplay

- Race against 5 AI opponents
- Navigate through obstacles and collect boost zones
- Use slipstream mechanics by positioning yourself on adjacent tracks to rivals
- Diagonal movement for changing tracks, smooth snapping when moving horizontally
- Track-based positioning ensures fair racing - vehicles ahead can block your track, but those behind cannot
- Momentum system rewards sustained horizontal movement

## Controls

- **Desktop**: Arrow keys to move, Space to boost, Escape to pause
- **Mobile**: Tap sides to move, tap both sides to boost, tap top to pause

Built with PixiJS v8. Optimized for mobile and desktop play.
